# Changelog

## Latest Version

- New: Toolbar setting (Settings > Appearance, under Pinned icon size): Horizontal, the default and the toolbar as before, or Vertical. Vertical moves the toolbar buttons into a narrow column at the left edge of the panel, in the same order from top to bottom, with the gear at the bottom of the column. The search rows, Favorites, the Space title, the tree and the page agent drawer take the rest of the width; the Space bar stays at the bottom, full width. In Vertical the hold-for-history lists of Previous / Next, the audio list and the gear menu open to the right of their button; in a panel too narrow for that they open below or above it. Apply switches the layout right away, in the side panel of every window
- New (experimental): page agent scripts. With the new Page scripts plugin (Settings > AI > Page agent plugins, off by default) the page agent can change how a page behaves with JavaScript, for example keys or player buttons on YouTube that seek to the previous or next subtitle line. It works as for CSS: it sets conditions it can check, applies the script with the new `apply_script` tool, checks it with `run_check`, which presses the keys or clicks and reads the values back, and reports each condition. Turning the plugin on first shows a warning about what scripts can do. The first script of a request shows its code and the site with Allow and Deny; Allow covers the rest of the request on that site only, so a script that navigates the tab to another site can't have the next one run there unseen, and Deny refuses every script of it and the agent goes on with CSS. Scripts run with `chrome.userScripts` in a separate world of the extension, one per site, in the page's top frame; they see the page's elements but not its JavaScript objects, and their fetch / XHR requests reach only the page's own site (navigation, new windows, frames and forms are not restricted). A script registers its listeners, timers, observers and added elements through `agent` helpers, so Undo removes them with the CSS, and a new script replaces the previous one as a whole. Show CSS is now Show code, with the CSS and the script, each with Copy. Re-apply runs the script again after a reload or on another page of the same site, and refuses on another site. Save to bookmark saves the script with the CSS, also a script with no CSS, and Auto-apply, the strip's Apply and the Page style submenu work with it; saved scripts run without asking, and the strip's Apply is off when the bookmark's tab shows another site. A script gets 10 seconds to finish and can be up to 64 KB. Turning the plugin on requests the new optional `userScripts` permission, which Chrome grants without a prompt of its own; Chrome also needs Allow User Scripts on the extension's Details page (Developer mode before Chrome 138; Chrome 135 or later), and the drawer and Settings say when it is off, with a button to fix it. The switch stops only the agent writing new scripts; turning off Allow User Scripts stops saved ones too. The scripts and what they return now go to the AI endpoint too; the tab's chat keeps them, and saved scripts are stored with the saved style
- New: Switch to Space 1 … 9 shortcuts. Each switches the focused window to the Space at that position in the Space bar, as a click on its icon does: the Space's most recently used tab comes forward, and a Space with no tabs gets a new tab. They have no keys by default; set them in `chrome://extensions/shortcuts`. A number past the last Space, or the number of the Space you are in, does nothing. On macOS `Cmd+1` … `Cmd+9` are Chrome's own tab shortcuts, so use `Control+1` … `Control+9`; if "Switch to Desktop N" is on in System Settings > Keyboard > Keyboard Shortcuts > Mission Control, macOS takes those keys, so turn it off first
- Changed: the Archive section, the Favorites grid and the Space title take less height - smaller section headers and tighter gaps around them
- Changed: closing the active tab switches to the tab you used before it in the same Space. Before, Chrome picked the tab next to it in the tab strip, which could be an unrelated tab or a tab of another Space, and with Follow active tab on the sidebar then switched Space. A Space with no other open tab gets a new tab and stays active. This works for X in the sidebar, `Cmd+W`, the tab strip and pages that close themselves; commands that close many tabs at once (Close Other Tabs, Clear, Archive, Close All Tabs In Space) land on one tab instead of hopping through several. Closing a background tab or a whole window works as before, and so does closing the active tab after a browser restart before you switched tabs once

## 2.0.387

- New: markdown notes in Space folders. New Note in a folder's menu adds a note at the end of the folder and opens it in a tab, in the editor: a title, the markdown text, Save (also Cmd+S / Ctrl+S) and Cancel. Save also renames the note's bookmark ("Untitled note" for a blank title), and leaving the tab with unsaved changes asks first. Opened again, the note shows rendered (headings, bold, italic, code, lists, quotes, rules and http(s) links, which open in a new tab) with the time of its last edit and an Edit button. A note is a Chrome bookmark whose URL is the extension's `note.html?id=<noteId>` page, so moving, renaming, deleting with Undo, Open All, Open as Tab Group and the Arc-style tab work as for other bookmarks, and note tabs re-attach to their bookmarks after a browser restart. Note rows in the tree and the Archive show a notebook icon. The text is stored on this computer (`bookmarkNotes` in `chrome.storage.local`), not in the bookmark; on another computer a synced note bookmark opens a page that says the text is stored elsewhere. Duplicate copies the text to a new note. Deleting a note bookmark keeps its text for 30 days, so Undo brings it back, then deletes it if no bookmark points at the note. Export and Import have a Notes checkbox: the backup carries the texts, Import restores them without importing bookmarks again, keeps a text that is as new or newer here, and points the note bookmarks it creates at this install. Copy as YAML copies a note's link, not its text. Recently Closed now records this extension's note tabs. In unpacked builds, loading `dist/` from another path changes the extension id, and existing note links stop opening
- New: ready-to-load zips on the GitHub Releases page, so you can install the extension without building it from source. Install in the README explains how to load the zip and how to update it without losing your settings and Spaces
- Fixed: dragging a tab, tab group or link into a Space with no bookmarks shows a blue drop line under the Space title, and the drop saves the bookmark in the Space. It no longer lands next to the Space folder, where the tab vanished from the Tab list. A drop in the empty area under the last bookmark now adds it at the end of the Space, not at the top
- New (experimental): page agent plugins and Video transcripts. A new Page agent plugins group in Settings > AI switches the agent's optional tools on and off, from the next request; the first plugin, Video transcripts, is on by default. With it the agent reads the subtitles of the video on the page with the new `read_video_transcript` tool, to summarize the video, say what happened so far or explain what was just said. It takes the language you ask for; otherwise on Prime Video the original language, on other pages the subtitles shown in the player, else English, else the first track. On Prime Video (`primevideo.com`, and Prime titles on Amazon stores, also under `/<Title>/dp/<ASIN>`) the first video question after a page load adds a `fetch` wrapper to the page that records the subtitle list Prime's player loads when it opens, and asks you to close the player with ✕ and press Play again; the subtitle file is then downloaded inside the page, without cookies, only from Prime's subtitle servers. Reloading the page removes the wrapper. On other pages it reads the subtitle and caption tracks of the largest visible video without turning captions on; videos inside embedded frames can't be read. Against spoilers, a video past its first minute and before the end of its subtitles is read only up to the playback position, and the answer says up to which time it goes; the agent reads on to the end only when you ask about the whole video or its ending. "What was just said" reads the two minutes before the position, and when the position isn't known the agent asks how far you watched. One read returns up to 60,000 characters. The subtitle text now goes to the AI endpoint too; the plugin switches are stored with the AI settings
- New (experimental): the page agent answers questions about the page. Ask "summarize this page" or "explain <term>" and it reads the text of the page's main content (up to 30,000 characters) with the new `read_page_text` tool and replies in the chat as an Answer, rendered as markdown: headings, bold, italic, code, lists, quotes and links, which open in a new tab. Only http and https links work, HTML in an answer shows as text and images don't load. A question the agent asks back is an Answer too, no longer Not done; a style change that set conditions still ends only with its report. Follow-ups see the earlier answers, up to 4,000 characters each. Show on page under an answer opens it in a popup at the top right of the page, with a ✕ and a button that collapses it to its title bar; asked to show the answer on the page, the agent opens the popup itself with the new `show_popup` tool. While the popup is open, each later answer is added to it under its question and the popup scrolls to it, expanding first if collapsed; after ✕ answers go to the chat only. A new popup replaces the open one, a reload or a move to another page removes it, and style changes don't touch it. The page's text and earlier answers now go to the AI endpoint too
- New (experimental): save the page agent's CSS to a bookmark or Favorite. Save to bookmark, next to Undo and Show CSS, stores it for the bookmark the tab was opened from; after a follow-up change it reads Update saved style, and Saved when nothing changed. With Auto-apply on, the default for a new saved style, the extension puts the style back whenever a page of the same site loads in that bookmark's tab: after a reload, on the next page, after Back and after a browser restart, also with the side panel closed. A hand-opened tab of the same site stays unstyled, and so do other sites in the bookmark's tab. A strip under the drawer's header shows the bookmark's name, an Auto-apply switch, Apply, which puts the saved style on the page in place of the current CSS, and Remove. The chat takes a style the extension applied as its current CSS, so Undo removes it, Show CSS shows it and a follow-up edits it. Bookmark rows with a saved style show a brush, blue with Auto-apply on and gray with it off. The right-click menu of a bookmark or Favorite with a saved style has a Page style submenu with Auto-apply on load and Remove saved style. Deleting the bookmark or its folder deletes its style, and Undo of the delete brings it back. Saved styles are stored locally and aren't part of Backup. Auto-apply needs a tab linked to the bookmark, which the Arc style Open bookmark mode makes. The extension now requests the `webNavigation` permission, to notice when a page starts loading in a bookmark's tab
- New (experimental): page agent. The sparkles button in the toolbar opens a drawer at the bottom of the panel with one chat per tab. Describe a change to the page and the agent reads the page outline (and a screenshot when "Model accepts images" is on), sets measurable conditions, applies CSS to that tab only, measures the result in up to 8 rounds (plus one last turn that can only report) and reports each condition as met or unmet with the numbers. A follow-up message edits the current CSS and shows replaced conditions as replaced. Undo removes the agent's CSS, Show CSS shows and copies it, and after a reload or on another page of the same site Re-apply puts it back. It uses the AI naming endpoint, model and API protocol (Responses API or Chat Completions) with tool calling; CSS that would load anything from the network is rejected. Chats last for the browser session and are deleted when their tab closes (or the next time a side panel opens, if none was open). New "Model accepts images" setting in the AI tab (off by default), and a new optional `<all_urls>` permission, asked for only to take screenshots
- Fixed: AI naming reads a page's Markdown version and the page links in `llms.txt` only from the page's own site and doesn't follow their redirects, so a page can no longer make the extension fetch another host (such as your router or a local server) and send the answer to the AI endpoint. A relative Markdown link of a bookmark renamed without an open tab now resolves against the page instead of failing
- Changed: the AI Base URL must use HTTPS; HTTP is allowed only for localhost (`localhost`, `*.localhost`, `127.x.x.x`, `[::1]`), e.g. Ollama or LM Studio. A saved remote `http://` Base URL now fails Validate and AI rename with "Base URL must use HTTPS (HTTP is allowed only for localhost)"; it is not rewritten
- Fixed: a bookmark marked for attention stays visible when its folder or the Bookmarks section is collapsed, even without an open tab; the live-tabs filter still hides it while it has no tab
- New: Copy as YAML and Paste from YAML... in a bookmark folder's menu, and Copy Space as YAML and Paste from YAML... in the Space title's `...` menu (hidden when the Space has no bookmark folder). Copy puts the folder (or the Space folder's contents) on the clipboard as a YAML list of folders (`folder`, `items`) and bookmarks (`title`, `url`), without `asd_Archive` and `asd_Favorites`. Paste checks the whole text first, shows what it will create or the line and reason of each error, and creates nothing until it is valid; it adds `https://` to URLs without a scheme, uses the URL when `title` is missing, rejects folders named `asd_Archive` or `asd_Favorites`, appends to the end of the folder without merging same-named folders, and one Undo removes the whole paste
- New: Archive button on hover and Archive in the right-click menu of a tab or a multi-selection - saves the tabs to the Space's Archive and closes them, with Undo; marked tabs stay open. Dragging tabs onto the Archive section (collapsed or expanded) does the same
- New: Recently Closed button on the Space title (shown on hover when the Space has closed tabs) - hover or click it for the Space's recently closed tabs, newest first, with the time each was closed. Click one to reopen it in the current window and that Space, without its Back/Forward history; Clear empties the list. Up to 50 per Space, kept across browser restarts; the same page closed again replaces its older entry. Tabs closed by auto-archive or the Archive button, bookmark and Favorite tabs, tabs a tab suspender replaces with its park page, incognito tabs and internal pages are not recorded. Deleting a Space deletes its list
- Fixed: an invalid URL in New Bookmark shows its error only in the dialog; it no longer stays under the Bookmarks tree after the dialog closes
- New: the search button on the Space title (hover or click, Arc style) shows the recently used pages of the whole Space folder, newest first, with search, like the button on a folder row
- Changed: hovering a tab or bookmark shows a flag button that marks it for attention or clears the mark, in place of the Pin button. Pin to Sidebar stays in the right-click menu and is now also in a single bookmark's menu and in the menu of a selection of several bookmarks
- Changed: each Space has its own Favorites. They are bookmarks in an `asd_Favorites` folder inside the Space's bookmark folder, so they sync with Chrome bookmarks and survive reinstalling the extension; custom icon, emoji and color stay in local storage (`favoriteIcons`). On update, the old global Favorites are copied once into every Space that has a bookmark folder, and open Favorite tabs keep their Favorite in their own Space. A Space without a bookmark folder shows a hint instead of Favorites. The Bookmarks tree, search, Expand All, Open All and folder pickers hide `asd_Favorites`
- New: Move to Space in a Favorite's right-click menu - moves it to another Space's Favorites; its open tab moves to that Space too
- Changed: the Tab Switcher lists a Favorite tab only in its own Space. Auto-archive never closes a tab on the page of any Space's Favorite
- Changed: JSON export and import work on the active Space's Favorites. Arc import puts Arc's Favorites into every Space it creates, or into the active Space
- Fixed: a tab you opened by hand on a bookmarked or Favorite page no longer jumps out of the Tab list into the bookmark (or into another Space) when another bookmark opens or closes. Open bookmark pages are still re-linked after a browser restart or extension reload
- New: `...` menu on the Archive header with Clear - Clear All, Older than 24 Hours, Older than 7 Days, Older than 30 Days. It clears the active Space's whole Archive regardless of the search; each option shows its count and is grayed out at 0. Clear All asks for confirmation; one Undo restores everything a Clear removed
- New: Mark for Attention in the right-click menu of tabs and bookmarks, also for a multi-selection - a marked row gets a ring; the item reads Clear Mark on a marked row. A marked tab's close button shows `-`, which clears the mark and leaves the tab open. Auto-archive never closes a marked tab, and bulk close commands (Close Tabs Before / After, Close Other Tabs, closing a selection, Close Tabs in Group, Clear, Archive, Close All Tabs In Space) leave marked tabs open. Marks survive a browser restart; incognito tabs can't be marked. The "Mark for Attention colour" setting (Settings > Appearance) picks the ring's colour - green, blue, orange, red, purple, yellow or the Space colour (the active Space's colour, also with the sidebar tint off; theme violet in the All view) - and strength: dim, normal or bright. The default is Space colour - dim
- Fixed: the active bookmark row now lines up with the other rows and is as wide as they are
- New: Edit submenu in a bookmark's right-click menu, as in Arc - "Replace Pinned URL with Current" sets the bookmark's URL to the page its open tab shows now (the title stays); "Edit Pinned Page" opens the edit dialog. It replaces "Rename..."
- Fixed: a tab opened from a link in a bookmark or Favorite page (Cmd+click) now goes to the top of the Tab list instead of a random spot
- New: "Mark unvisited tabs" setting (Settings > Appearance, on by default) - a dot at the left edge of a Tab list row marks a tab opened in the background until you first switch to it. Tabs restored with a closed window (Cmd+Shift+T) or brought back by Undo get no dot
- New: "Highlight tabs by last use" setting (Settings > Appearance, on by default) - Tab list rows get a stronger background the more recently you left the tab, fading out over 3 hours; looks: White, Accent, Cooling, Trail, or Off. Accent and Trail use the Space colour when it tints the sidebar
- New: "Archive tabs after" setting (Settings > Behaviour, off by default) - tabs unused for 12 hours to 30 days are saved to the Space's `asd_Archive` bookmark folder and closed; open bookmark pages close and keep their bookmark
- New: Archive section between Bookmarks and Tabs - expand it to list archived tabs, newest first, and search them from the header row; click one to reopen it
- New: `...` menu on the "+ New Tab" row with Archive and Clear, replacing the Clear button. Archive saves the Tab list's tabs to the Space's Archive and closes them right away; Undo reopens them and removes the new archive items
- New: collapse the Bookmarks section with the chevron on the Space title; collapsed, it still shows the open bookmark pages
- New: double-click a bookmark (Arc mode) or a Favorite whose tab has moved to another page to load the bookmarked page back in that tab
- Fixed: double-clicking a bookmark or Favorite with no open tab no longer opens two tabs
- Changed: Favorites tiles are a third lower and follow the "Pinned icon size" setting - a smaller icon gives lower tiles and more of them per row
- New: Tab Switcher - hold the modifier and press its shortcut to list the current Space's tabs and Favorites, most recently used first; press again to move, release to switch. Assign the shortcut in `chrome://extensions/shortcuts`
- New: Space Switcher - the same for Spaces; picking a Space opens its most recently used tab
- Removed: the Space Navigator window (Cmd+Shift+S) - the Space Switcher replaces it
- Changed: the extension now requests the `activeTab` permission (no install warning), used to draw the switcher list over the current page
- Changed: clicking a Space or swiping to it brings that Space's most recently used tab forward; a Space with no tabs opens a new tab
- Fixed: opening a bookmark no longer switches the sidebar to another Space when its tab had been recorded under the wrong Space
- Changed: the extension now requests the `alarms` permission (no install warning), used only while "Archive tabs after" is on
- Fixed: right-clicking the "Create a Space" placeholder header no longer opens an empty menu
- Fixed: after a browser restart, a reused tab ID no longer gives a pinned page's identity or a Space assignment to an unrelated tab on another site
- New: the search button on a bookmark folder row (hover or click) shows the folder's recently used pages, newest first, with search
- Improved: collapsed folders now keep all of their open pages visible, not only the active one
- Changed: Spaces now use persistent extension-owned Tab assignments instead of creating Chrome native tab groups
- Fixed: opening Spaces across multiple windows no longer accumulates duplicate Saved Tab Groups
- New: Arc-style folder collapse states, active descendant peek, New Tab ordering, and one-Space-at-a-time navigation
- Improved: fixed-page and Favorite recovery across Side Panel reopen, external tab suspension, and Chrome tab switching
- Improved: Arc-aligned active rows, folder icons, spacing, translucency, menus, and bottom Space navigation
- Fixed: tab history navigation (including keyboard shortcuts) and audio quick-jump now always take you to the tab, even when "Follow active tab" is Off
- Fixed: "Show active tab" button now works when the active tab is in another space

## 1.0.349

- Space membership is now independent from Chrome native tab groups; native groups remain user-owned
- Existing extension-owned live groups are ungrouped without closing their tabs during migration
- Added persistent Tab-to-Space recovery across extension reloads, browser restoration, navigation, sorting, and cross-window moves
- Removed the visible All Space and aligned folder, active-tab, New Tab, Favorites, and context-menu behavior more closely with Arc
- Fixed fixed-page duplication and stale active state after reopening the Side Panel or switching through Chrome's native tab UI
